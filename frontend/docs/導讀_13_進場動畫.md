# 導讀 13：進場動畫

這份寫給組員看，說明進場動畫做了什麼、怎麼運作、要改的話改哪裡。對應決策 Q111。

## 1. 動畫在演什麼

主題是核心價值「零空檔：保證接得上」。一條線從頭到尾都在畫面上，每一幕都由上一幕變出來，中間不切鏡頭：

| 幕 | 時間（完整版） | 畫面 | 意思 |
|---|---|---|---|
| ① 比對 | 0～0.6 秒 | 深色網格上散落幾百個點，寫著「比對場次 · 餐廳 · 班次」 | 當天所有組合 |
| ② 剪枝 | 0.4～1.25 秒 | 灰點淡掉，留下的青色點排成一條路線：步行、電影、晚餐、捷運、到家 | 只留下接得上的 |
| ③ 歸零 | 1.25～2 秒 | 段與段之間的橘色空檔收合，上方計時器從 `GAP 00:12` 變成青色的 `00:00`，一個光點沿路線跑過去 | 每一段都接上了 |
| ④ 成錶 | 1.8～2.7 秒 | 路線像捲尺一樣捲成一個圓，60 個刻度依序亮起，畫出 ZG 和 ZEROGAP 字樣 | 錶盤＝精準時刻（Logo） |
| ⑤ 展開 | 2.8～3.2 秒 | 鏡頭穿過錶盤：錶盤放大衝出畫面，中間打開一個圓形視窗露出網頁 | 從品牌進到產品 |

顏色都用夜色主題的品牌色：青色 `#62d6e8`（接得上的路線，唯一主色）、橘色 `#ffb547`（偏緊的空檔）。展開後才換成使用者自己的日／夜主題。

## 2. 什麼時候播

| 情況 | 播哪一版 |
|---|---|
| 掃 QR 碼或貼網址，第一次打開首頁 | 完整版，約 3.2 秒 |
| 第一次打開其他頁（分享行程 `/p/…`、方法頁等） | 縮短版，約 1.15 秒：畫一圈錶圈 → 刻度 → ZG → 展開 |
| 同一個分頁換頁、重新整理 | 不播（`sessionStorage` 的 `zg-intro-seen`，關掉分頁就清掉） |
| 手機開了「減少動態」 | 不播 |
| Playwright 等自動化測試 | 不播（不影響其他測試）；網址加 `?intro=1` 強制播 |
| 網址加 `?intro=0` | 不播 |

點一下畫面，或按 Esc、Enter、空白鍵就略過。

## 3. 為什麼寫在 index.html 裡

手機掃 QR 碼後，網頁程式（React，gzip 後約 146 KB）要先下載完才畫得出畫面，慢速 4G 要一兩秒，這段時間原本是白畫面。進場動畫不經過 React，打包時直接寫進 `index.html`，**HTML 和樣式表（CSS）一到就開始播**，等待的時間就是動畫本身。（CSS 本來就會擋住整頁的第一次繪製，所以動畫也是等 CSS 到了才看得到，這點和原本一樣。）

- 動畫播到錶盤畫完（完整版 2.8 秒、縮短版 0.8 秒）時，如果網頁還沒準備好，就停在錶盤上慢慢轉著等；等到 React 畫出外框（`AppShell` 呼叫 `markAppReady()`；連外框都出錯時由錯誤頁呼叫）才展開。最多等 8 秒，之後照樣展開。
- 播完會把自己整個移除，恢復捲動和網址列顏色，並發出 `zg:splash-done` 事件。播放中網頁改了網址列顏色（例如日間主題），動畫會先維持深色，播完才換成網頁要的顏色。
- 保險：畫面出錯就立刻收掉；瀏覽器一直不跑動畫的話，13 秒後也一定收掉，不會把網頁蓋住。
- 點擊一直擋到動畫完全移除，連點兩下想略過時，第二下不會按到底下看不見的按鈕。
- 動畫元素有 `aria-hidden`；播放中底下的網頁設成 `inert`，按 Tab 不會跑到看不見的連結上，播完就拿掉。

## 4. 檔案

| 檔案 | 做什麼 |
|---|---|
| `src/splash/splash.ts` | 全部的動畫。上半部是純函式（播不播、播哪版、每一幕的進度、等待和略過），下半部 `boot()` 用 Canvas 畫 |
| `src/splash/splash.test.ts` | 純函式的單元測試 |
| `src/splash/ready.ts` | `markAppReady()`：告訴動畫網頁準備好了 |
| `vite.config.ts` 的 `inlineSplash` | 把 `splash.ts` 去掉型別、包成立即執行的 script，正式版再壓縮，寫進 `index.html` 的 `<body>` 最前面 |
| `e2e/splash.e2e.ts` | 流程測試：預設不播、完整版（含 `inert`）、縮短版、點一下略過、網頁晚到時停在錶盤等、減少動態 |
| `src/app/AppShell.tsx`、`src/app/RouteError.tsx` | 畫出來時呼叫 `markAppReady()` |
| `scripts/measure-perf.mjs` | 多量一列「首頁＋開場動畫」和「開場結束 秒」 |

**改 `splash.ts` 要注意**：它會被直接寫進 HTML，所以**不能 import 任何東西**，`export` 都要寫在行首。開發時改了它，網頁會整頁重新載入。

## 5. 想調整的話

- 每一幕的時間：`frameState()` 裡的 `span(t, 開始, 結束)`；總長度和等待點在 `TOTAL`、`HOLD_AT`。
- 路線的五段名稱：`LABELS`。
- 大小：`layout()` 裡的 `R`（錶盤半徑）、`LL`（路線長度）、`k`（大螢幕放大倍數）。
- 想重看：網址加 `?intro=1`，或開新分頁。
