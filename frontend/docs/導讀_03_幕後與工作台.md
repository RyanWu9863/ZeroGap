## 2. 條件寫進網址（Q62）

**比喻**：以前條件只寫在你自己的筆記本（瀏覽器暫存）；現在也印在車票上（網址），把車票交給別人，他拿到的行程跟你一樣。

```
/result?from=中壢站&to=桃園區&date=2026-10-30&t=17:00-23:00&food=日式&budget=1000&walk=12&plan=2
```

| 規則 | 說明 |
|---|---|
| 預設值不寫 | 「不限」「沒有」「幫我挑」不出現在網址，網址比較短 |
| 別的參數不動 | `?proto=`、`?mock=` 原封不動保留 |
| 誰優先 | 網址有條件就用網址的，沒有才用瀏覽器暫存 |
| 寫壞了 | 網址缺欄位或數字不合法，就改用暫存，不會整頁壞掉 |

檔案：`src/features/result/urlState.ts`（轉換，有 5 個測試）、`useResultState.ts`（同步）。

這不是「分享連結」功能（MVP 不做清單裡有），畫面上沒有分享按鈕，只是網址剛好可以複製。

## 3. 改條件的小視窗（Q58）

結果頁頂端的每個條件標籤都可以點，點了會在旁邊彈出小視窗：

- 小視窗裡**直接沿用精靈的元件**（月曆、時間滑桿、車站搜尋、按鈕列），所以操作方式跟精靈一模一樣。
- 改完按「重算」才生效；按「取消」、點旁邊或按 Esc 都會放棄這次修改。
- 重算時播約 1 秒的短版動畫（Q54），網址同步更新。

檔案：`ConditionBar.tsx`（標籤＋小視窗）、`ConditionEditor.tsx`（八種編輯器）。小視窗用 shadcn 的 Popover（底層是 Base UI）。

## 4. 低信心挑選頁（Q22、Q87）

當 Jev 的信心低於 0.60（閥門沒過），結果出來之前會先問一題：

> 快好了，再問一題：這幾部都接得上，你比較想看哪一部？

- 不出現「信心不足」「Jev」這類字眼（Q16）。
- 挑了就把它當條件重算一次；也可以按「都可以，幫我決定」直接看結果。
- 不確定的是餐廳時，問「你比較想吃哪一家？」。這需要後端在 request 加 `restaurant_name`，已寫進 API 變更提案 #6。

**怎麼預覽**：網址加 `?mock=low_confidence`，電影選「幫我挑」。

**為什麼「Jev」和機率只出現在這一頁**：竹老師說使用者畫面不要寫 AI；評審想看深度，就來這一頁看（Q16）。

**延遲載入**：圖表套件（Recharts）比較大，所以這一頁是「進來才下載」，不拖慢首頁。

### 圖表的顏色是驗證過的

用 dataviz 的驗證工具檢查過三版的「保留（強調色）／淘汰（灰）」兩個顏色：

- 色盲也分得出來（CVD ΔE 都 > 8）
- 一般視覺分得出來（ΔE > 15）
- 對背景的對比 ≥ 3:1

工具會對灰色報「彩度太低」，但灰色本來就是用來表示「不重要」的弱化色，不是分類色，所以這一條不適用。另外每張圖下面都有「用表格看」，讓色弱或投影看不清楚的人也能讀。

## 7. 測試時要知道的一件事

在 Claude 的瀏覽器面板「沒有顯示」時，瀏覽器會暫停畫面動畫（`requestAnimationFrame`）。這時切換方案，舊的時間軸會停在退場動畫、看起來沒換。這是測試環境的限制，**正常使用不會發生**；改用「網址帶 `plan=3` 重新載入」驗證過，選方案的邏輯是對的。
