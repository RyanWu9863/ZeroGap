## 4. 備援方案

| 狀況 | 怎麼辦 |
|---|---|
| 後端（串接後）連不上 | 按 B →「展示模式」打勾。畫面頂端會出現橘色「展示模式」標籤，**講一句「現場網路不穩，切到預先錄好的回應」**，不要假裝是即時查詢 |
| 動畫跑太久或卡住 | 按右下角「略過動畫」 |
| 不小心點錯頁 | 按 H 回首頁，再按 1 |
| 筆電當機 | 用第二台筆電（事先 `npm install` 好），從清單第 3 項開始 |

⚠️ **目前的「展示模式」用的還是開發用假資料**；後端串好之後要錄製真的回應（第 9–10 天的工作）。在那之前，畫面上會一直顯示「假資料（開發用）」，Demo 時要老實說明「後端串接中，這是用 API 合約範例資料跑的畫面」。

## 6. 評審可能問的問題

| 問題 | 回答重點 | 根據 |
|---|---|---|
| 你們怎麼「保證」接得上？ | 五道關卡由 Python 確定性計算；前端顯示的每段緩衝也是後端算好傳過來的，前端不自己算 | AI_CONTEXT 鐵律、決策 Q41 |
| Jev 在這裡做什麼？為什麼不用 LLM 算？ | Jev 只在「已經接得上」的方案裡排序；時間金額讓 LLM 算會有幻覺風險，所以禁止 | AI_CONTEXT §2 |
| 信心不夠怎麼辦？ | 閥門 0.60，沒過就不硬選，改問使用者「你比較想看哪一部」 | 決策 Q22、Q87 |
| 價格準嗎？ | 拿不到真實價格時標黃底「約」，試用中 ＿／＿ 人看得懂黃底的意思 | 決策 Q24、試用數據 |
| 資料多新？ | 結果頁底部寫資料更新時間；某個來源匯入失敗時會變橘色提醒，系統幕後有完整狀態 | 決策 Q63、驗收 A9 |
| 為什麼使用者畫面沒寫 AI？ | 使用者在乎幾點到家，不在乎用了什麼技術（指導老師建議）；技術細節都在系統幕後 | 決策 Q16 |
| 為什麼只有桃園、只有電影？ | MVP 先把一個場景做紮實；縣市和娛樂類型的選單已經預留，顯示「即將開放」 | 決策 Q17b、Q31 |
| 前端怎麼確保跟後端格式一致？ | 用 zod「驗貨單」檢查每一筆回應，格式不對立刻報錯；後端好了改成從 OpenAPI 自動產生型別 | 決策 Q72 |
| 有測試嗎？ | 37 個單元測試＋6 條使用流程，在 Chrome 和 Safari 核心各跑一次（共 12 個）；`npm run predemo` 一鍵全跑 | 決策 Q77、Q89 |
| 手機能用嗎？ | 桌機優先，手機版已調整版面；流程測試有跑 Safari 核心（iPhone 用的） | 決策 Q5、Q64 |
| 怎麼證明好用？ | 試用 ＿ 人：平均 ＿ 秒看懂、＿ 秒拿到行程，＿／＿ 人覺得比自己查快 | 試用計畫 |
| MCP 在哪裡？ | v2；網頁和 Agent 用同一份 API 合約，系統幕後有說明 | 決策 Q92 |

「＿」的數字在第 13 天試用後填入。
