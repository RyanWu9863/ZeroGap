# 試用計畫（第 13 天）

> 目的：用真人數據回答 MVP 的成功指標，同時決定 A／B／C 三版要選哪一版。
> 對應決策：Q79（計時）、Q80（問卷）、Q90（第 13–14 天找 5–10 人試用）、Q98（組員檢查點）。

---

## 1. 這次試用要回答什麼

| 問題 | 怎麼量 | 及格線 | 對應 MVP |
|---|---|---|---|
| 30 秒內看得懂網站在做什麼嗎？ | 「看懂用途」秒數：從主持人按開始，到試用者按進精靈 | 平均 ≤ 30 秒 | 成功指標 1 |
| 1 分鐘內拿得到行程嗎？ | 「排行程」秒數：從進精靈，到三個方案出現 | 平均 ≤ 60 秒 | 成功指標 2 |
| 看得懂黃底是估計值嗎？ | 問卷第 1 題 | 答對 ≥ 7 成 | 假設 H3 |
| 願意照這個行程出門嗎？ | 問卷第 2 題（1–5） | 平均 ≥ 3.5 | 假設 H3 |
| 比自己查三個 App 快嗎？ | 問卷第 3 題 | 「是」≥ 7 成 | 假設 H2 |
| 哪一版最好用？ | 三版各自的平均秒數＋願意程度 | 見第 6 節 | 決策 Q37b |

## 2. 找誰、找幾個

- **9 個人**，A／B／C 各 3 位（系統會自動輪流分配）。
- **不要找組員**，也不要找看過我們報告的人，他們已經知道怎麼用了。
- 最好有幾位平常會搭大眾運輸出門的人。

## 3. 事前準備（前一天）

1. `npm run predemo`，看到「✅ Demo 前檢查全部通過」。
2. 準備一台筆電（Chrome）和一個滑鼠。
3. 印出第 4 節的**任務卡**，和第 5 節的**觀察紀錄表**（一人一張）。
4. 打開 `http://localhost:5173/?trial=1`，到「系統幕後」最下面把舊的試用紀錄清掉。
5. 關掉其他分頁和通知。

## 4. 任務卡（念給試用者聽，或給他看）

> 你住在中壢，**明天**晚上想去**桃園區**看電影、看完再吃**日式**晚餐。
> **17:00 以後**才能出門，**23:00 前**要回到中壢站。每人預算 **1,000 元**以內，影城走到餐廳最多 **12 分鐘**。
> 請用這個網站排出行程，排好後告訴我：幾點出門？看哪一場？吃哪一家？幾點回到中壢站？每人多少錢？

**為什麼要指定條件**：後端還沒完成，現在用的是假資料，不管填什麼條件，都會回傳「中壢站 → 桃園區、看完再吃、日式」的同一組行程。照任務卡填，結果才會跟試用者的需求一致，問卷的回答才準。

最後那一句「告訴我幾點出門…」對應 MVP 成功指標 3（使用者能從結果直接回答五個問題），由主持人記在觀察表上。

## 5. 每位試用者的流程（約 5 分鐘）

| 步驟 | 主持人做什麼 |
|---|---|
| 1 | 畫面上是「第 N 位試用者」，版本已自動選好，不用改 |
| 2 | 請試用者坐好，念任務卡，然後按「**試用者坐好了，開始計時**」 |
| 3 | **不要提示、不要幫忙**；只在觀察表記他卡住的地方 |
| 4 | 三個方案出現後，請他口頭回答任務卡最後的五個問題 |
| 5 | 右下角跳出 3 題問卷，請他自己填完按「送出」 |
| 6 | 主持人按「**下一位試用者 →**」，回到第 1 步 |

**主持人可以說**：「你覺得下一步要做什麼？」「你在找什麼？」
**主持人不要說**：「按這裡」「那個是估計值」「往下滑」。試用者問問題時，回答「你覺得呢？」並把問題記下來。

## 6. 試用完怎麼整理

1. 到「系統幕後」→「試用紀錄」，按「**下載 CSV**」，存到 Google Drive 的 ZeroGap 資料夾。
2. 填下面這張彙整表（上半直接抄系統幕後的數字）：

| 指標 | 全部 | A 時刻表 | B 電影感 | C Linear 風 |
|---|---|---|---|---|
| 人數 | | | | |
| 平均看懂秒數（≤ 30） | | | | |
| 平均排行程秒數（≤ 60） | | | | |
| 黃底答對 | | | | |
| 願意採用（平均，≤ 5） | | | | |
| 覺得比自己查快 | | | | |
| 能答出五個問題（平均） | | | | |

3. **選版本的規則**（建議，組內可以改）：
   1. 先刪掉「平均排行程秒數 > 60」的版本；
   2. 剩下的比「願意採用」平均分數；
   3. 差距小於 0.5 分時，看觀察表裡「卡住」的次數，少的勝出；
   4. 最後組內 4 人再投一次票確認（決策 Q38）。

4. 觀察表裡**出現 2 次以上的卡點**，列進修正清單，第 14 天上午修。

## 7. 要老實說明的地方

- 9 個人的數字只能說「初步試用」，不能說成統計顯著。
- 用的是假資料：秒數量的是**介面好不好用**，不是真實資料的正確性。
- 每個人只用了一個版本，版本之間的比較會受到「不同人」的影響。
