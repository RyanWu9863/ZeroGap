# 導讀 05：iPhone（iOS Safari）適配

> 2026-10-20。原本是「桌機優先，手機能看就好」（決策 Q5），這一版把手機版補到「好用」。

---

## 1. 一句話

用 WebKit（Safari 的核心）模擬 iPhone SE（320 寬）和 iPhone 13（390 寬），三個試做版、八個頁面全部檢查過：**畫面不會左右晃、輸入框不會讓畫面自動放大、按鈕手指點得到**，並把這些檢查變成自動測試。

## 2. 怎麼找問題的

寫了一支稽核程式，每一頁都：

1. 截一張完整的手機截圖；
2. 量 `scrollWidth`：大於螢幕寬，就代表整頁可以左右滑（手機上很難用）；
3. 數「小於 32px 的按鈕和連結」：Apple 建議點擊目標至少 44pt；
4. 數「字小於 16px 的輸入框」：iOS Safari 點到這種輸入框會自動放大畫面。

修正前後：

| 檢查 | 修正前 | 修正後 |
|---|---|---|
| 會左右晃的頁面（iPhone SE） | 介紹頁、精靈 ①、結果頁、系統幕後 | 0 |
| 會讓 iOS 放大的輸入框 | 1（車站搜尋） | 0 |
| 結果頁太小的點擊目標 | 29 | 只剩文字內連結（例如地點名稱），屬於可以接受的例外 |

## 3. 修了什麼

### iOS 專屬

| 問題 | 修法 |
|---|---|
| iPhone 瀏海和底部橫條會擋內容 | `viewport-fit=cover`，固定在底部的按鈕列都加上安全區域留白；橫放時左右也避開瀏海 |
| 點輸入框畫面被放大 | 手機上輸入框字級 16px（桌機維持 14px） |
| 毛玻璃效果在舊版 iOS 沒作用 | 加上 `-webkit-backdrop-filter` 前綴 |
| 點按時出現灰色方塊 | 關掉 iOS 預設的點擊高亮 |
| 橫放時字被自動放大 | `text-size-adjust: 100%` |
| 數字被自動變成電話連結 | `format-detection: telephone=no` |
| 網址列顏色 | `theme-color`，跟著三個試做版的底色變 |
| 加到主畫面沒有圖示 | `apple-touch-icon.png`（`npm run icons` 重新產生），名稱「零空檔」 |

### 版面

| 問題 | 原因 | 修法 |
|---|---|---|
| 精靈 ① 在 SE 上超出畫面 | `<fieldset>` 預設最小寬度等於內容寬度 | 加 `min-w-0` |
| 介紹頁範例時間軸超出畫面 | 緩衝標籤前面有固定縮排，文字也不能換行 | 手機不縮排，標籤可以換行 |
| 結果頁可以左右滑 | 估計值 ⓘ 的說明框就算看不見也佔著位置 | 說明框只有打開時才存在，並靠右對齊 |
| 系統幕後圖表超出畫面 | 格子裡的圖表把格子撐寬 | 格子加 `min-w-0`；桑基圖在窄螢幕改成可以左右滑 |
| 「試做版」切換鈕擋住內容 | 手機上整排鈕浮在畫面中間 | 手機上縮成一顆小圓鈕，點了才展開；試用、簡報模式時完全隱藏 |

### 手指好不好點

用 Tailwind 的 `pointer-coarse:` 只對「用手指操作」的裝置放大，桌機滑鼠不受影響：

- 選項按鈕、月曆日期、條件標籤：至少 40～44px 高
- 時間滑桿的圓鈕：22px → 30px
- 路線示意圖的站點：加一圈看不見的大圓，放大點擊範圍
- ⓘ 按鈕：點擊範圍放大

### iPhone 才會發生的 bug

**估計值的 ⓘ 說明在 iPhone 上打不開**。原本是滑鼠移上去或聚焦時顯示，但 iOS Safari 點按鈕**不會**觸發聚焦，所以 iPhone 使用者永遠看不到「此價格為估計，實際以現場為準」，驗收 A8 的說明等於失效。改成「點一下打開、再點一下關掉」。

## 4. 自動測試

流程測試多了 **iPhone 13** 這個專案（WebKit、觸控、390 寬）：

- 原本 6 條流程在 iPhone 上全部再跑一次；
- 新增 2 條只在 iPhone 跑的測試：6 個頁面都不會左右晃、搜尋框字級 ≥ 16px；ⓘ 點一下看得到說明。

`npm run e2e` 現在是 20 個通過＋4 個略過（手機專屬測試在桌機上自動略過）。

## 5. 還沒確認的

- **真的 iOS Safari**：這台 Mac 的 Xcode 沒有安裝 iOS 模擬器映像，所以這次是用 Playwright 的 WebKit 模擬。版面、觸控、字級都驗過，但雙頭時間滑桿在真機上的拖曳手感還要用真的 iPhone 試一次。安裝模擬器：`xcodebuild -downloadPlatform iOS`（好幾 GB）。
- **最好的確認方式**：試用那天請一兩位同學用自己的 iPhone 打開。電腦和手機連同一個 Wi-Fi，執行 `npm run dev -- --host`，用手機打開終端機顯示的 Network 網址即可。
